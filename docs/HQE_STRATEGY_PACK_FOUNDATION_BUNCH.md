# HQE Strategy Pack Foundation Bunch

This cohesive roadmap bunch combines:

1. Versioned strategy-pack JSON schema
2. Strict paper-only safety validation
3. Seven built-in strategy packs
4. Current locked forward candidate as a protected pack
5. Strategy registry and discovery
6. JSON import/export
7. Clone-as-draft versioning
8. App-native Strategy Pack Center

Built-in packs:

- Breakout option-buy
- Momentum/trend option-buy
- Reversal option-buy
- Scalping option-buy
- Carry/BTST research-only
- Sideways-avoidance filter
- Locked forward-validation candidate

Permanent safety:

- Paper/research only: YES
- Real money: NO
- Real orders: NO
- Broker execution: NO
- Auto trading: NO
- Option selling: NO
- Fake trades: NO
- Locked-candidate tuning during validation: NO

This is not a profitability claim.
