# HQE Strategy Builder and Selector Bunch

This cohesive roadmap bunch combines:

1. Visual paper-only strategy form
2. Category-aware rule defaults
3. Entry, filter, exit and risk validation
4. Strategy preview with warnings
5. Save-as-draft workflow
6. Active paper-strategy selection
7. Selection clearing and status
8. App-native Strategy Builder & Selector Center

Supported builder categories:

- Breakout
- Momentum/trend
- Reversal
- Scalping

Supported index symbols:

- NIFTY
- BANKNIFTY
- FINNIFTY
- SENSEX

The active selection file is a paper-only configuration pointer. It does
not execute a strategy, place orders or connect to broker execution.

Permanent safety:

- Paper-only selection: YES
- Real money: NO
- Real orders: NO
- Broker execution: NO
- Auto trading: NO
- Option selling: NO
- Fake trades: NO
- Locked-candidate tuning during validation: NO

This is not a profitability claim.
