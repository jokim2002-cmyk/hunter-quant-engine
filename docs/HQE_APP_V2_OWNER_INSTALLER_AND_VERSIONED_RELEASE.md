# HQE App V2 Owner Installer and Versioned Release

## Purpose

This pack adds an owner-machine installation flow without administrator privileges.

## Included

- Versioned installer package
- Current-user LocalAppData installation
- Desktop shortcut creation
- Version metadata
- SHA-256 installer manifest
- Launch wrapper with preflight
- Uninstall flow
- Install verification utility

## Current boundary

This remains a source-based owner-machine installation. It depends on the HQE
repository virtual environment and is not yet a fully standalone compiled
Windows installer.
