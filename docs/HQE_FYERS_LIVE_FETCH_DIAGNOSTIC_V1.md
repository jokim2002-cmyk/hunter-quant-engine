# HQE Fyers Live Fetch Diagnostic V1

This diagnostic discovers the current Fyers data-only fetcher, filters watch processes to actual Python executables, captures one-shot fetch stdout and stderr, compares CSV and status files before and after execution, and writes structured evidence.

It does not place orders, execute through a broker, or enable auto trading.

- Real money: NO

- Auto trading: NO
