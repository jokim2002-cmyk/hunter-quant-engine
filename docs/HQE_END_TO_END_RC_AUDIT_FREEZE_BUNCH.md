Audit integrity:

- Snapshot failures caused by incomplete market evidence are marked for
  review rather than being hidden.
- Missing release files, failed guards, unsafe app calls, invalid launcher
  assets or freeze-hash mismatches are blocking failures.
- The audit never starts paper watch, fetches data, runs backtests, generates
  validation reports, connects broker execution or places orders.

Freeze scope:

The freeze covers the paper/data/research product release candidate.
Real trading and broker execution remain outside this release.

This is not a profitability claim.
