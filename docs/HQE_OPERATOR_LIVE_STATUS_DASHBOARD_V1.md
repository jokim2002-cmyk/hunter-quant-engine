# HQE Operator Live Status Dashboard V1

The operator dashboard is a read-only UI for the active paper/data workspace.

It displays:

- Paper Watch status
- data freshness
- latest update timestamp
- selected broker
- selected symbol
- latest controlled-run decision
- latest evidence folder
- hard safety locks

It refreshes every five seconds and contains no order placement or broker-execution controls.

Safety:

- Real money: NO
- Real orders: NO
- Broker execution: NO
- Auto trading: NO

This is not a profitability claim.
